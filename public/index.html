    El método

    Combinamos un modelo Poisson calibrado con cuotas reales de mercado para detectar value bets matemáticamente.

    i.

    Modelo Poisson

    Calculamos la probabilidad real de cada resultado usando forma reciente, goles esperados y ventaja de localía. Misma técnica que casas profesionales.

    λₗ · Aₗ · Dᵥ · 1.15
    P(h,a) = Pois(λₗ) · Pois(λᵥ)
    ii.

    Probabilidad implícita

    Convertimos la cuota del mercado en probabilidad: si pagan 2.40, el mercado está diciendo 41.6% de probabilidad implícita.

    prob_mercado = (1 / cuota) × 100
    iii.

    Detección de EDGE

    El edge es la diferencia entre nuestra probabilidad calculada y la implícita del mercado. Edge positivo > 3% = value bet.

    EDGE = prob_modelo − prob_mercado
